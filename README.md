# lessmade.com

The live site: Jared Erickson's Loose Wall / Orbit portfolio, served by GitHub Pages at lessmade.com.

This folder is generated. Edit `folio/site-build/wall2.html` and `wall.json`, then run

    python3 folio/site-build/golive.py [edits-dir]

to copy the page (as `index.html`), `wall.json`, the thumbnail and full-size packs (`thumbs/`, `full/`),
videos (`video/`) and About photos (`about/`) here. Commit and push to publish.
