# lessmade.com

The live site: Jared Erickson's portfolio, served by GitHub Pages at lessmade.com. The front page is the Desk; the Loose Wall / Orbit is wall.html.

This folder is generated. Edit `folio/site-build/desk.html`, `wall2.html` and `wall.json`, then run

    python3 folio/site-build/golive.py [edits-dir]

to copy the Desk (as `index.html`), the Loose Wall (as `wall.html`), `wall.json`, the thumbnail and full-size packs (`thumbs/`, `full/`),
videos (`video/`) and About photos (`about/`) here. Commit and push to publish.
